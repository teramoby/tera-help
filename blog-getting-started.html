Getting Started with tt by teramoby: A Multi-Model AI Client

tt is a native multi-model AI client for iPhone, iPad, Mac, and Android that lets you query multiple LLMs at once and receive a single, synthesized answer.

Large language models have transformed how people interact with information, but one fundamental problem remains stubbornly unsolved: hallucination. Models generate plausible-sounding answers with apparent confidence, and users have no reliable way to know whether what they're reading is actually true. You ask a question, you get a well-written answer — but is it right?

A separate but equally overlooked problem: powerful enterprise LLM services — AWS Bedrock, VolcEngine Ark, and others — have long lacked a polished end-user client. They're API-first by design, built for developers, and that technical barrier has kept most people from using them directly.

tt addresses both. It dispatches the same question to multiple independent LLMs simultaneously — OpenAI, Anthropic, AWS Bedrock, DeepSeek, and more — and collects their responses in parallel. Where models agree, confidence is higher. Where they diverge, the disagreement itself is worth examining. tt then sends all responses to a designated summarizer model, which synthesizes them into a single, well-rounded final answer.

Setting Up API Keys

tt is a client — it doesn't supply AI of its own. Data flows directly from your device to the provider; nothing passes through our servers. To get started, you'll need an API key from at least one provider, entered in Settings → Providers. Direct links to each provider's key page:

Configure two or more providers if you can. The more models in the mix, the richer the perspectives feeding into the final answer.

Asking Your First Question

Once your keys are in, you're ready. The workflow is simple:

Select your models

On the main screen, pick one or more models to query at the same time.

Type your question and send

tt fires the request to all selected models in parallel.

Read each model's response

Responses come back simultaneously. You can read each model's full answer individually.

Get the synthesized answer

tt sends all responses to the summarizer model, which produces one objective, reliable final answer.
