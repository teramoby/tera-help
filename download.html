Install the APK Carefully

Android may ask you to allow APK installation for the browser or file manager you used. Grant access only to the app handling this download, install the package from this page, and turn that permission off again when it is no longer needed.

If Android refuses an update or reports a signature conflict, do not uninstall the existing app until you have considered your local data. Conversations and settings are stored as app data on the device, and encrypted API keys are excluded from Android system backup. An uninstall or fresh setup can require you to configure provider keys again.

Keep Your Installation Up to Date

  • iPhone, iPad, and App Store Mac: install updates through the App Store according to your automatic-update settings.
  • Direct Mac build: this site does not state that the DMG has an in-app updater. Return to this page to compare the currently published package before replacing an installed copy.
  • Android APK: compare the version shown here with the installed version. Install a newer official package over the existing app only when Android accepts it as an update.

What You Need Before Your First Chat

tt uses a bring-your-own-key model. The app does not include an AI subscription, so you need credentials and available API access for at least one supported provider or hosting platform. Provider billing, quotas, model access, and regional availability remain part of your own provider account.
