# tt by teramoby

[tt by teramoby](https://app.teramoby.com/) is a native, bring-your-own-key multi-model AI client for Mac, iPhone, iPad, and Android. Connect AI services available to your own accounts, compare their original responses, synthesize common points and differences, or let models share a discussion in Team Mode.

## Privacy model

Conversation history and settings remain as app data on the user’s device, while provider credentials use the device platform’s secure system storage. Model requests go to the services the user configures. Online Search has a separate, documented data flow. Read the [BYOK guide](https://app.teramoby.com/byok-privacy.html) and [Privacy Policy](https://app.teramoby.com/privacy.html) before using sensitive information.
