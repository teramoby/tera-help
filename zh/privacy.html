隐私政策

tt by teramoby（以下简称“tt”）不保存您的任何信息。所有数据仅存储在您的设备上，开发者在技术上无任何途径获取您的数据。

数据存储

数据本地存储

您在 tt 中产生的所有数据——包括对话记录、应用配置、偏好设置——均仅保存在您所安装的设备上。我们没有云端同步、没有远程备份，也没有任何形式的服务器端存储。

零数据收集

tt 不收集、不记录、不传输任何用户数据，包括：对话内容与历史记录、使用行为与统计、设备信息与标识符、地理位置信息，以及任何个人身份信息（PII）。

数据安全

开发者无法访问您的数据

tt 不设任何后端服务器、数据管道或遥测系统。即便开发者想获取您的数据，在技术上也无从实现。您的隐私受到架构层面的保护，而非仅依赖于承诺。

API 密钥安全

您配置的第三方 AI 服务商 API 密钥，仅存储于本地设备的系统安全存储中。这些密钥不会传输给 tt 开发者，也不会用于其他任何目的。

第三方服务

第三方 AI 服务商

tt 的核心功能是将您在对话框中输入的文本内容（消息与提示词）直接从您的设备传输至您主动选择并配置的 AI 服务商（如 OpenAI、Anthropic、Google Gemini 等），以获取 AI 生成的回复。传输通过您自己提供的 API 密钥与服务商直接建立连接，tt 不对此内容进行拦截、存储或任何形式的处理。

此数据传输完全由您主动发起：您自主决定使用哪家服务商、配置对应的 API 密钥，并在每次对话时决定发送的内容。您对所有数据的流向拥有完全控制权。您的对话内容仅用于向所选服务商请求回复，不作任何其他用途。

各 AI 服务商将依据其自身隐私政策处理收到的数据，与 tt 无关。建议您在使用前阅读所选服务商的隐私政策，以了解其数据处理方式。
