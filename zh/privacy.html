隐私政策

tt 会把对话、设置和凭证作为应用数据保存在您的设备上。模型请求会发送给您配置的 AI 服务；联网搜索处于开启状态时，生成的搜索词还可能发送到下文说明的 teramoby 搜索服务。

如需先了解服务商请求、本地存储与凭证边界，可阅读更易理解的BYOK 与本地隐私指南。

数据存储

数据本地存储

您的对话记录、服务商配置和偏好设置作为应用数据保存在设备上。tt 不提供 teramoby 账户或自有云同步服务；操作系统可能依据平台设置，将本地应用数据纳入系统备份或设备迁移。在 Android 上，对话记录、服务商配置和偏好设置可以随系统备份或设备迁移，已加密的 API 密钥不包含在该备份中。

不向 teramoby 发送分析数据

tt 不会为了账户同步、广告或产品分析，把完整对话历史、使用分析、广告标识、位置或个人身份信息发送给 teramoby。为提供特定功能而必须离开设备的数据，会在“第三方服务”和“联网搜索”中说明。

数据安全

本地数据不会提供给 teramoby

tt 不使用 teramoby 账户、自有云同步管道或遥测服务，因此 teramoby 无法通过应用获取保存在本地的对话、设置或凭证。平台备份服务商可能依据您的操作系统账户和备份设置处理被备份的应用数据。

API 密钥安全

您配置的第三方 AI 服务商 API 密钥存储在设备的系统安全存储中。密钥仅在认证请求时发送给对应服务商，不会发送给 teramoby 或无关服务。

第三方服务

第三方 AI 服务商

为生成回复，tt 会把您的消息及当前工作方式所需的上下文，从设备直接发送给每个已经完整配置模型和凭证的 AI 服务（如 OpenAI、Anthropic、Google 或 DeepSeek）。标准多模型综合和 Team Mode 的后续请求，可能包含其他模型的回答或共享讨论上下文。

您决定配置哪些服务以及提交哪些内容。各服务商会依据自己的条款和隐私政策处理收到的请求；teramoby 不处于模型服务商的请求链路中。

联网搜索

联网搜索（RAG）使用由 teramoby 运营并托管在 Cloudflare 的搜索服务。当前 Android 接口为 https://wanjucool.com/api/search；当前 Apple 实现使用对应的 https://terasear.wcai.workers.dev/api/search 路径。搜索服务会收到根据提示词生成的简短搜索词；返回的结果随后可能作为上下文发送给已配置的 AI 服务商。

搜索接口会把搜索词发送给上游搜索来源，并使用 Cloudflare KV 将搜索词和返回结果临时缓存最长五分钟。teramoby 未为该接口配置专用的 Worker 日志导出；Cloudflare 和上游搜索来源仍可能依据各自条款处理搜索词及常规请求元数据。

当前版本默认开启联网搜索。当前 Android 版本会先由已配置的总结模型判断是否需要最新网络资料；当前 Apple 实现会在联网搜索开启时对非空提示词进行搜索。您可以在设置中关闭联网搜索，以阻止应用使用搜索服务。如果您配置自己的 Search API Key，它会替代应用内置的接口凭证，保存在本地安全存储中，并仅为认证而发送至搜索接口。

请查看每项已配置 AI 服务的隐私和保留条款。模型服务商、Cloudflare、平台备份服务商及上游搜索来源会依据各自条款处理其收到的数据。
