一个客户端，连接多家主流 AI 服务

tt 把模型服务商和 AI 托管平台放进同一个原生客户端，让你集中连接常用服务，不必在多个应用之间搬运对话。

tt 采用自带密钥（BYOK）方式，你连接自己账户中已有权限的服务。标准对话和 Team Mode 会使用所有模型和凭证均已完整配置的服务；只配置一个服务就是单模型对话，配置多个服务就是多模型对话。tt 不捆绑 AI 订阅，也不转售服务商的调用额度。

面向普通用户的聊天订阅与 API 权限通常是两个独立产品。例如，ChatGPT Plus 不包含 OpenAI API 调用，Claude 付费订阅也不包含 Anthropic Console API 调用。连接其他服务前，同样需要查看其开发者平台和计费说明。

连接支持具体意味着什么

使用你自己的账户与凭证

你需要拥有对应服务的有效账户和凭证；服务商的计费、额度、地区可用性和内容规则仍然适用。

模型列表会随服务更新

模型名称和可用性会变化。tt 持续维护服务连接，应用内的可选模型列表也会随之更新。

在同一个地方使用

配置完成后，各家服务会同时出现在 tt 中。对话会使用所有模型和凭证均已完整配置的服务。

保留每份原始回答

标准多模型对话会保留各模型已完成的回答，同时显示总结模型整理出的综合答案。

两种多模型使用方式

标准多模型对话

把同一个问题发送给所有配置完整的服务，比较各自的原始回答，再由你指定的总结模型整理为一份综合答案。需要更严谨地评估时，可使用这套可复现的 AI 回答比较方法。

Team Mode 讨论

让所有配置完整的服务进入共享对话，彼此回应、补充新信息，并在没有新的有效信息时不再重复发言。查看 Team Mode 的工作方式。

多模型回答可以呈现不同前提和视角，但多个模型得出一致结论，也不代表已经得到事实验证。涉及医疗、法律、财务等重要事项时，请依据可靠来源另行核验。
