基础功能

tt 支持哪些模型服务商与托管平台？

tt 已提供 OpenAI、Anthropic、Google、xAI、DeepSeek、Kimi、豆包、通义千问、智谱 GLM、MiniMax 等模型服务商，以及 AWS Bedrock、Azure AI、Google Vertex AI、阿里云 Model Studio 等托管平台的连接配置。账户权限、地区、额度和可用模型仍由各服务决定。完整信息请查看模型服务商与托管平台页面，当前配置项以应用内列表为准。

为什么需要我自己的 API 密钥？

模型请求会从您的设备直接发送到已配置的 AI 服务商。联网搜索处于开启状态时，生成的搜索词可能会发送到由 teramoby 运营、Cloudflare 托管的搜索服务；当前 Android 版本会先由总结模型判断是否需要最新资料。各平台行为和完整数据流请查看隐私政策。

如何添加 API 密钥？

打开 tt，进入「设置 → 模型配置」，选择对应的服务商，将 API 密钥粘贴到输入框并保存。密钥会安全存储在设备的系统安全存储中，不会以明文形式保存在普通文件里。

综合答案是如何生成的？

在标准对话中，tt 会把问题发送给当前所有模型和凭证均已完整配置的服务，保留每个已完成的原始回答，再交给您指定的总结模型。只配置一个服务时，会直接显示该服务的回答。结果仍是模型生成内容，重要信息应另行核验。

什么是 Team Mode？

Team Mode 会让当前所有模型和凭证均已完整配置的服务进入同一段共享讨论。模型可以回应用户和其他模型、补充新信息、质疑前提，也可以在没有新内容时不再发言。输入 @ 可以点名一个模型优先回应，但不会排除其他参与者。当所有参与者都不再补充时，讨论会自动结束。了解 Team Mode 的工作方式。

什么时候用标准对话，什么时候用 Team Mode？

需要快速回答、并排比较或综合结果时使用标准对话；需要批评、权衡利弊，或希望多个模型在共享上下文中彼此补充时使用 Team Mode。

隐私与安全

tt 会保存我的对话记录吗？

会。对话历史作为应用数据保存在您的设备上；操作系统可能依据平台设置，将这部分本地数据纳入系统备份或设备迁移。在 Android 上，对话历史和设置可以随系统备份或设备迁移，已加密的 API 密钥不包含在该备份中。

我的 API 密钥安全吗？

API 密钥存储在设备的系统安全存储中，不会以明文形式写入普通文件。密钥仅用于向您配置的服务商认证，不会发送给 teramoby 或无关服务。

tt 会收集使用数据或分析数据吗？

tt 不会把使用分析、广告标识或完整对话历史发送给 teramoby。您发起的请求仍会发送给已配置的 AI 服务商；联网搜索处于开启状态时，生成的搜索词可能会发送到由 teramoby 运营、Cloudflare 托管的搜索服务。当前版本默认开启联网搜索，您可以在设置中关闭。各平台行为、接口、缓存和第三方处理详情请查看隐私政策。

下载与费用

tt 是免费的吗？

tt 应用本身免费下载使用。您只需为实际使用的 AI 服务商 API 调用支付费用，费用由各服务商按其定价标准收取，与 tt 无关。

支持哪些平台？

tt 支持 Android、iPhone、iPad 和 Mac。Android 版本可从官网直接下载；在已上架的 App Store 地区，可搜索 teramoby 并选择“teramoby tera (tt)”。目前中国大陆 App Store 暂未上架。
