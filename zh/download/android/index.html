安装后需要准备什么

tt 采用自带密钥（BYOK）方式。下载安装包不会附带 AI 订阅、调用额度或共享的服务商访问权限。开始对话前，你需要拥有受支持的服务商或托管平台账户，选择完整的模型，并提供该服务所需的凭证。服务可用性、计费、限额、模型权限和数据条款仍由你自己的服务商账户决定。

  1. 打开 tt，进入“设置 → 模型配置”。
  2. 选择你的账户可用的服务，然后输入该服务所需的凭证。
  3. 选择模型并保存。完整配置一个服务即可进行单模型对话；配置多个服务即可使用多模型工作流。
只在指定的配置字段中输入服务商密钥。不要把 API Key 粘贴到对话消息、搜索框或不可信网页中。服务商支持时，建议设置预算、限额，并使用权限范围尽可能小的凭证。
