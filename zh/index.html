多模型 AI 客户端

一个客户端，连接国内外主流大模型。既可以自由选择模型单独对话，也可以让多个模型共同讨论并生成综合答案。

  • 连接国内外主流大模型与托管平台
  • 在同一个 App 中自由选择模型对话
  • Team Mode 让不同模型彼此讨论、补充和质疑
  • 整合不同模型的共识与分歧，生成综合答案

隐私

您的数据， 只属于您。

数据本地存储

您的所有对话记录、配置信息均仅保存在您所安装的设备上，不会上传至任何服务器。

零数据收集

tt 不收集、不记录任何用户数据，包括但不限于对话内容、使用习惯、设备信息及个人身份信息。

开发者无法访问您的数据

tt 的开发者在技术层面无任何途径访问您的数据——我们没有后端服务器，没有数据管道，也没有任何遥测系统。

API 密钥安全

您配置的第三方模型 API 密钥仅保存在本地设备的安全存储中，tt 开发者无从获取，也不会将其用于任何其他目的。

tt 直接在您的设备上与您所选择的 AI 服务商通信。请参阅您所使用的模型服务商的隐私政策，了解其数据处理方式。
