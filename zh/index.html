隐私

本地优先， 数据流向说清楚

数据本地存储

对话记录和配置信息作为应用数据保存在设备上；操作系统可能将这部分数据纳入系统备份或设备迁移。

不向 teramoby 发送分析数据

tt 不会为了产品分析而把完整对话历史、使用分析、设备标识或个人身份信息发送给 teramoby。

没有 teramoby 账户或云服务

tt 不使用 teramoby 账户、自有云同步、数据管道或遥测服务。

API 密钥安全

第三方 API 密钥保存在设备的系统安全存储中，仅用于向你配置的服务认证，不会发送给 teramoby。

模型请求会从你的设备直接发送到已配置的 AI 服务商。联网搜索处于开启状态且确有搜索需要时，生成的搜索词会发送到由 teramoby 运营、Cloudflare 托管的搜索接口。备份、缓存和第三方处理详情请参阅隐私政策。
