tt by teramoby 正式发布

适用于 Android、iPhone、iPad 及 Mac 的多模型 AI 客户端，让不同模型共同讨论，并由 AI 汇总生成综合答案。

teramoby 今日宣布 tt by teramoby 正式发布。tt 是一款适用于 iPhone、iPad、Mac 及 Android 的多模型 AI 客户端，支持用户同时向多个主流大语言模型发起查询，并将所有回答汇总，由 AI 综合生成一个客观可靠的最终答案。

当前主流 AI 应用通常依赖单一模型，而不同模型对同一问题往往给出差异显著乃至相互矛盾的回答。tt 通过并行调用 OpenAI、Anthropic、Google 等多家主流服务商的模型，同步获取多个独立视角的回答，再将所有结果汇总交由一个模型进行综合整理，生成兼顾多方意见的最终答案。

最可靠的答案，不一定来自最强的单个模型，而是来自多个独立视角的汇聚。tt 让这一过程变得触手可及。

tt 采用自带密钥（BYOK）模式，用户自行提供各 AI 服务商的 API 密钥。所有对话数据直接在用户设备与服务商之间传输，不经过 teramoby 的任何服务器，从架构层面确保数据隐私。

上市信息

tt by teramoby 现已提供下载，支持 iPhone、iPad、Mac 及 Android。App Store 显示名称为“teramoby tera (tt)”。使用时需自行准备所选 AI 服务商的 API 密钥。

如何使用

从 App Store 下载

通过本站 App Store 直达链接，或在 App Store 搜索 teramoby，找到“teramoby tera (tt)”后即可在 iPhone、iPad 或 Mac 上免费安装。

配置 API 密钥

打开 tt，进入「设置 → 模型配置」，选择你想使用的 AI 服务商（如 OpenAI、Anthropic 等），粘贴对应的 API 密钥并保存。密钥会安全存储在系统安全存储中。

选择模型并提问

在主界面选择你想同时调用的模型，输入问题后发送。tt 会并行向所有选中的模型发起请求，同步获取各自的回答。

获取综合答案

tt 将所有模型的回答汇总，发给一个模型进行综合整理，生成客观可靠的最终答案。
