适用于 Android、iPhone、iPad 和 Mac 的多模型 AI 客户端：标准对话可以比较并综合多个回答，Team Mode 可以让模型围绕同一问题继续讨论。

teramoby 今日宣布 tt by teramoby 正式发布。tt 是一款适用于 iPhone、iPad、Mac 及 Android 的多模型 AI 客户端，支持用户同时向多个大语言模型提问、查看各自回答，并由所选总结模型整理成综合答案。

当前主流 AI 应用通常依赖单一模型，而不同模型对同一问题往往给出差异显著乃至相互矛盾的回答。tt 通过并行调用 OpenAI、Anthropic、Google 等多家主流服务商的模型，同步获取多个独立视角的回答，再将所有结果汇总交由一个模型进行综合整理，生成兼顾多方意见的最终答案。

你可以查看完整的模型服务商与托管平台连接列表，也可以进一步了解模型如何在 Team Mode 中彼此回应。

一个模型提供一种视角。tt 把多种视角放进同一次对话，让你同时看见共识与分歧。

tt 采用自带密钥（BYOK）模式，用户自行提供各 AI 服务商的凭证。模型请求从设备直接发送给已配置的服务商；tt 不会为了账户同步或分析而把完整对话历史或凭证上传给 teramoby。联网搜索采用单独的数据流，详情已在隐私政策中说明。

如何使用

从 App Store 下载

通过本站 App Store 直达链接，或在 App Store 搜索 teramoby，找到“teramoby tera (tt)”后即可在 iPhone、iPad 或 Mac 上免费安装。

配置 API 密钥

打开 tt，进入「设置 → 模型配置」，选择你想使用的 AI 服务商（如 OpenAI、Anthropic 等），粘贴对应的 API 密钥并保存。密钥会安全存储在系统安全存储中。

输入问题并发送

在主界面输入问题后发送。tt 会并行向所有模型和凭证均已完整配置的服务发起请求，同步获取各自的回答。

查看综合答案

tt 将已完成的回答交给你选择的总结模型，整理共同点和差异，形成一份综合答案；重要信息仍应另行核验。
