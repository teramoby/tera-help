谨慎安装 APK

Android 可能要求允许浏览器或文件管理器安装 APK。只给实际处理本次下载的应用临时授权，从本页下载并安装；不再需要时可以关闭该权限。

如果 Android 拒绝更新或提示签名冲突，在处理本地数据前不要卸载现有应用。对话和设置作为应用数据保存在设备上；已加密的 API 密钥不包含在 Android 系统备份中。卸载或全新安装后，你可能需要重新配置服务商密钥。

保持安装版本更新

  • iPhone、iPad 与 App Store Mac 版：依据自动更新设置，通过 App Store 安装更新。
  • Mac 直接下载版：本站没有说明 DMG 是否带应用内自动更新。更新前请回到本页，对比当前提供的安装包。
  • Android APK：将本页版本号与已安装版本对比；仅在 Android 将新官方安装包识别为更新时，覆盖现有应用安装。

首次对话前需要准备什么

tt 采用自带密钥（BYOK）模式，不包含 AI 服务订阅。你需要准备至少一家受支持的模型服务商或托管平台凭证，并确保自己的账户拥有可用 API 访问权限。计费、额度、模型权限和地区限制均由你的服务商账户决定。

在设备上安装 tt

使用上方与你的平台对应的官方下载，并完成操作系统的正常安装流程。

添加服务商凭证

打开「设置 → 模型配置」，选择服务，输入 API Key 或所需凭证，选择模型并保存。

使用一个或多个模型

完整配置一个服务即可开始单模型对话；配置多个服务后，可以进行多模型对话或使用 Team Mode。
