如何配置 tt 并开始多模型对话

tt 是适用于 iPhone、iPad、Mac 与 Android 的原生多模型 AI 客户端。本文说明如何连接 AI 服务、完成第一次提问并阅读结果。

在标准对话中，tt 会把同一个问题发送给所有模型和凭证均已完整配置的服务，保留每个模型的原始回答，再由你指定的总结模型整理共同点和差异，形成一份综合答案。只配置一个服务时，tt 会直接显示该服务的回答。

Team Mode 是另一种工作方式：参与模型会阅读共享讨论、回应彼此，并在没有新内容时停止发言。无论哪种模式，模型生成的内容仍可能出错；涉及重要决定时，请采用结构化比较方法，查看原始回答并依据可靠来源核验。

安装

通过本站 App Store 直达链接，或搜索 teramoby，找到“teramoby tera (tt)”后免费下载。首次启动时请阅读隐私说明，然后进入应用。

⚠️ 注意：由于合规要求，tt 目前暂不在中国区 App Store 上架。

配置 API 密钥

tt 本身不提供 AI 能力——它是一个连接各家服务商的客户端。模型请求会从你的设备直接发送到已配置的服务商；联网搜索处于开启状态且确有搜索需要时，生成的搜索词还会发送到隐私政策说明的搜索接口。使用前，请先在至少一家服务商处申请 API 密钥，并在 tt 的「Settings → Providers」中填入。以下是部分常用服务商的官方页面：

添加凭证前，建议先阅读BYOK 与本地隐私指南，了解哪些内容保留在设备上、哪些内容会发送给服务商。

查看当前模型服务商与托管平台连接列表；具体配置项以应用内列表为准。

配置两个或更多服务商可以比较更多视角，但模型数量本身不能保证答案正确；请查看原始回答并核验重要信息。

开始提问

配置完成后即可使用。流程很直接：

检查已配置服务

对话会使用所有模型和凭证均已完整配置的服务。

输入问题并发送

tt 会将问题同时发给所有配置完整的服务，并行等待回答。

查看各模型的原始回答

各模型的回答并行返回，可以分别查看每个模型的完整原始答案。

查看综合答案

tt 将已完成的回答交给总结模型整理为一份综合答案；你仍然可以随时返回查看每份原始回答。
