如何使用 tt by teramoby：多模型 AI 客户端入门

tt 是一款让你同时向多个 AI 模型提问、并得到一个综合答案的原生客户端，适用于 iPhone、iPad、Mac 及 Android。

大语言模型在过去几年重塑了人机交互的方式，但一个根本问题始终没有得到解决：幻觉（Hallucination）。模型会以高度自信的语气生成看似合理、实则错误的内容，而用户几乎没有可靠的手段来判断一个回答是否值得信任。你问了一个问题，得到了一个听起来很有道理的答案——但它是真的吗？

与此同时，另一个问题同样被忽视：企业级 LLM 服务——例如 AWS Bedrock、火山引擎方舟——拥有强大的模型能力，却长期缺乏面向普通用户的成熟客户端。这类服务的访问方式以 API 调用为主，技术门槛将大多数潜在用户拒之门外。

tt 尝试同时解决这两个问题。它将同一个问题同时提交给多个独立的 LLM——包括 OpenAI、Anthropic、AWS Bedrock、DeepSeek 等——并行收集各自的回答。多个模型得出一致结论时，可信度显著提升；出现分歧时，分歧本身就是值得审视的信号。最终，tt 将所有回答汇总发给一个指定的总结模型，生成兼顾多方视角的综合答案。

安装

通过本站 App Store 直达链接，或搜索 teramoby，找到“teramoby tera (tt)”后免费下载。首次启动时请阅读隐私说明，然后进入应用。

⚠️ 注意：由于合规要求，tt 目前暂不在中国区 App Store 上架。

配置 API 密钥

tt 本身不提供 AI 能力——它是一个连接各家服务商的客户端，数据直接从你的设备发往服务商，不经过任何中间服务器。使用前，需要在各服务商处申请 API 密钥，然后在 tt 的「Settings → Providers」中填入。以下是各服务商密钥申请页面的直链：

  • ChatGPT (OpenAI)获取 API Key →
  • Claude (Anthropic)获取 API Key →
  • Grok (xAI)获取 API Key →
  • Gemini (Google)获取 API Key →
  • DeepSeek获取 API Key →
  • AWS Bedrock获取 API Key →
  • 火山引擎 (VolcEngine)获取 API Key →

如需了解最新支持的服务商列表，请参阅 app.teramoby.com/faq.html。

建议配置两个以上的服务商。模型越多，综合答案的参考维度越丰富，准确性和客观性也越高。

开始提问

配置完成后即可使用。流程很直接：

选择模型

在主界面勾选想同时调用的模型，一个或多个均可。

输入问题并发送

tt 会将问题同时发给所有选中的模型，并行等待回答。

查看各模型的原始回答

各模型的回答并行返回，可以分别查看每个模型的完整原始答案。

获取综合答案

tt 将所有回答汇总发给总结模型，生成一个客观可靠的最终答案。
